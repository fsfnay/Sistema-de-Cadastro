# Sistema de Cadastro — Lojas Brincos e Companhia

## Sobre ❗
    Sistema de cadastro para novos colaboradores desenvolvido como atividade acadêmica de programação em HTML e PHP.

## Objetivo 🎯
    Formulário para cadastro de novos colaboradores da empresa fictícia **Lojas Brincos e Companhia**.
    Após o preenchimento e envio do formulário, os dados são enviados pelo método `POST` para uma página PHP, que recebe as informações, armazena cada dado em uma variável e apresenta uma página de confirmação personalizada.

## Funcionalidades 🧠
    O formulário coleta:
      - Nome completo
      - Idade
      - Profissão
      - Salário pretendido
      - Experiência anterior
    Após o preenchimento dos dados, eles são enviados e é exibida uma janela de confirmação com os dados que foram preenchidos anteriormente.
